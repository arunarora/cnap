# Credits & Acknowledgements

The CNAP (Cloud Native Application Platform) project is built on the shoulders of giants. I gratefully acknowledge the following open-source projects, tools, and languages that make this platform possible.

## Core Components & Ecosystem

This project utilizes, integrates with, or is inspired by the following technologies. We encourage you to support these projects.

* **Helm** — [https://helm.sh/](https://helm.sh/)
    * Used for package management and deployment orchestration.
* **Kong Gateway** — [https://konghq.com/](https://konghq.com/)
    * Provides the API Gateway and Ingress controller layer.
* **Keycloak** — [https://www.keycloak.org/](https://www.keycloak.org/)
    * Powering the Identity and Access Management (IAM) infrastructure.
* **PostgreSQL** — [https://www.postgresql.org/](https://www.postgresql.org/)
    * Reliable storage for platform state and data.
* **Docker** — [https://www.docker.com/](https://www.docker.com/)
    * Containerization standards and runtime environment.
